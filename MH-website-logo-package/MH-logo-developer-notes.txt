MH LOGO — WEBSITE HANDOFF

Files:
- MH-logo-transparent.png — high-resolution transparent PNG; recommended general web use.
- MH-logo-transparent.webp — lossless WebP with transparency; use where WebP is supported.
- MH-logo-icon-512.png — square 512×512 transparent icon canvas; suitable as a starting point for favicon/app icon work.
- MH-logo-website.svg — SVG wrapper with embedded PNG (not a true vector logo).

Suggested HTML:
<img src="/assets/MH-logo-transparent.png" alt="MH company logo" width="240" height="auto">

Implementation notes:
- Keep the logo's aspect ratio; do not stretch it.
- Use the transparent PNG on dark or light backgrounds after checking contrast.
- The SVG file scales as an SVG container, but its artwork is raster-based. For crisp, infinitely scalable output, ask a designer to recreate/trace the logo as a true vector SVG or AI/EPS file.
- The source image was raster artwork, so this package does not claim to be an original vector master.
